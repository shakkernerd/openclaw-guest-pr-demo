# Label checks

Verify the parcel label before dispatch.

- [ ] The order ID matches the carton contents and dispatch paperwork.
- [ ] Each SKU and quantity matches the packed items, including kits or pairs.
- [ ] The entire order fits in this single carton (the generated label says 1 of 1).
- [ ] The recipient name is clearly readable.
- [ ] The delivery address is complete, including the street address, postcode, and destination country.
- [ ] The label is securely attached to the parcel.
