Portable usage & input format

This single HTML file contains its styles, review engine, and synthetic example. Save it as review.html and open it in a current browser. No server, internet, sibling files, or installation is needed.

A contained preview must permit scripts and downloads. If this preview blocks scripts, the startup warning stays visible and file selection stays disabled. If downloads do not appear, save this HTML file and open it directly in a browser tab. The page cannot override its host's sandbox or content-security policy.

Choose or drop one UTF-8 JSON array (maximum 5 MiB / 10,000 records). Each record must have exactly four string fields:

[{"eventId":"e1","parcelId":"PKG-1","type":"created","occurredAt":"2026-10-28T08:00:00Z"}]

Types: created, in_transit, delivered, cancelled. IDs are nonempty, trimmed, case-sensitive Unicode without control characters. Timestamps require a valid calendar date, explicit timezone, and at most three fractional digits. Unknown fields, duplicate keys, invalid UTF-8, BOMs, or any invalid record reject the whole file. A valid [] is an empty review; an empty file is invalid.

Parcel, issue, and text filters combine and never change whole-file totals. Inspecting is not selecting. Check individual exceptions for a deliberate handoff; Select all matches adds every matching exception across pages. Filters retain selection and the bar counts hidden selections. Download selected JSON includes exactly those selected complete exceptions, including hidden ones, in deterministic audit order. Clear selection removes all selections. Loading another file or Clear review clears prior results and selection.

Inspect each source's original JSON, timestamp, one-based record/line and zero-based UTF-8 byte range [start, end). A cross-parcel conflict stays complete even when only one parcel matches. Full affected-parcel timelines retain non-exception events too. Original input offers a byte-for-byte download; nothing overwrites your input or uses browser storage.

Review does not authorize shipment. No first, last, or latest event is chosen as a winner. A clean review is not clearance. Exception exports contain original evidence: handle downloaded files with the same care as the source.
