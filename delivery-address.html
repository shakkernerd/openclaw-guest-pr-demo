Delivery-address line editor

Enter one address line per box. Use Move up or Move down to reorder draft lines, then choose Format address. One nonblank line is enough. Line breaks stay in the draft but must be corrected before formatting. Spaces and accepted text are preserved.

Formatting does not verify a postal address or authorize dispatch. This page works offline and does not automatically save or send your draft.

    Offline draft interchange

    Choose a UTF-8 JSON file containing an array of strings, including []. Blank strings, LF line breaks, Unicode, surrounding whitespace, duplicates, and order are preserved as parsed values, not original JSON spelling or formatting. Any CR (\r) in a string is refused for the whole import because textareas normalize CR. A single leading UTF-8 encoding BOM is accepted; literal U+FEFF inside strings is preserved. CR/CRLF JSON whitespace outside strings is accepted. Malformed UTF-8/JSON, nonarrays, and nonstring entries are refused, not repaired. Blank and multiline drafts can be imported but still need correction before formatting.

    Reading and previewing never change your draft or formatted output. Check the staged JSON, then explicitly Replace or Cancel. You can keep editing or choose another file while reading. Replace applies only the shown snapshot and discards your then-current draft; Cancel and errors leave it alone.
